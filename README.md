# Code for "Interpreting Anomaly Detection in SDSS Spectra"

This repository organizes the code used in our paper. It consists of:

- [`sdss`](https://github.com/ed-ortizm/sdss): SDSS data processing
- [`autoencoders`](https://github.com/ed-ortizm/autoencoders): Variational autoencoder training
- [`anomaly`](https://github.com/ed-ortizm/anomaly): Anomaly scoring
- [`xai-astronomy`](https://github.com/ed-ortizm/xai-astronomy): LIME-based explanations of spectra

Each repo includes its own instructions and documentation.
